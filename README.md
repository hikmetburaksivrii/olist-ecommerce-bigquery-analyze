🏠 Project Overview: The Olist Dataset Is A Real-World Dataset That Simulates E-Commerce Transactions. Olist Provides Rich Details About Customer Interactions, Products, Orders And Reviews Within A Brazilian E-Commerce Platform Connecting Sellers With Buyers. This Dataset Is Ideal For Analyzing The Complexities Of An Online Marketplace.

In This Analysis, The Primary Focus Is Divided Into Two Key Business Cases: Sales & Revenue Performance And Customer Behavior Analysis, Examining Average Order Value AOV, Observed Customer Lifetime Value CLV, Seasonal Order And Revenue Trends, Repeat Purchasing Habits, High-Value Customer Profiles And Spend-Based Customer Segmentation To Support Strategic Decision-Making Processes.

🔄 Project Workflow: The Entire Analytical Process Was Executed End-To-End Within Google BigQuery Utilizing SQL. The SQL Queries In The Project Are Numbered And This Sequence Must Be Followed To Maintain Table Dependencies And Data Integrity. The Workflow Initiated With A Data Exploration Phase Where Schemas Were Inspected, Raw Data Was Cleaned And Necessary Transformations Were Performed. Subsequently, These Prepared Datasets Were Merged Into A Consolidated Primary Table Serving As The Single Source Of Truth For Operational Analytics.

Using The Primary Fact Table, Queries Were Prepared To Examine Average Order Value AOV Along With Seasonal Order And Revenue Trends. To Support Customer-Centric Behavioral Analytics, A Secondary Summary Table Containing Observed Customer Lifetime Value CLV Metrics Was Created. This Summary Layer Laid The Groundwork For Queries Aimed At Examining High-Value Customer Profiles, Repeat Purchase Rates And Customer Segmentation.

🤖 Technologies Used: Google BigQuery 🤖
